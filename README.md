# Ridlo Falihin — Personal Portfolio

Website portofolio responsif menggunakan HTML, CSS, dan JavaScript, disertai contoh backend PHP.

## Fitur
- Navigasi responsif untuk layar kecil
- Tombol tema terang/gelap
- Bagian profil, keterampilan, proyek, dan kontak
- Contoh formulir PHP dengan validasi dasar

## Menjalankan website statis
Buka `index.html` di browser atau gunakan ekstensi Live Server di VS Code.

## Menjalankan demo PHP
Pastikan PHP sudah terpasang. Dari folder proyek, jalankan:

```bash
php -S localhost:8000
```

Buka `http://localhost:8000` untuk portofolio dan `http://localhost:8000/contact.php` untuk demo formulir PHP.

## Sebelum dipublikasikan
1. Ganti tautan GitHub dan email contoh di `index.html`.
2. Pastikan deskripsi proyek sesuai dengan kontribusi dan hasil yang benar-benar kamu kerjakan.
3. Tambahkan URL repository/demo proyek yang sudah tersedia.
4. Uji tampilan di desktop dan ponsel.
5. Jangan memasukkan password, API key, atau informasi rahasia ke repository.

## Deployment
Website statis (`index.html`, `style.css`, `script.js`) dapat dipublikasikan menggunakan GitHub Pages atau layanan hosting statis lain. GitHub Pages tidak menjalankan PHP; untuk menjalankan `contact.php`, gunakan hosting yang mendukung PHP.
